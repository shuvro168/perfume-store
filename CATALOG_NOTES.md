# Product catalogue review

39 candidate product entries transcribed from the user-supplied image collage. All prices are USD 49 as instructed. Names with "verify" and ambiguous duplicate photos require confirmation. Only capacities clearly legible in the uploaded images have been entered; other sizes are intentionally blank.

The demonstration storefront uses placeholder images, **zero stock**, and **no checkout** to avoid representing unverified inventory as ready for sale. Replace product pictures only with licensed/authorized images or images you own. Verify trademarks, product authenticity, concentration, sizes, and shipping eligibility before enabling sales.

When Supabase is configured, the database takes over from the local demo catalogue. To import these items, create them in the admin or build a controlled import workflow; this file is not automatically synchronized with Supabase.
